# Vue Auth-API Analyzer

Scans Vue 3 projects for buttons with permission directives (e.g. `v-auth`), traces their backend API calls, and generates a complete **Button → Permission → HTTP API** mapping report.

## ⛔ Critical Rules

- **MUST use the script pipeline** — never manually analyze Vue source code
- **Never generate Markdown reports** — all output is JSON generated by the script
- **Never list function names as APIs** — "app.getAppsList" is NOT an API; it must be "GET /iam/apps"
- **Never split pipeline steps** — use `--run-ai` for full analysis

## Setup

### Install the tool (first time only)

```bash
cd {baseDir} && npm install
```

### LLM Credentials

**No extra setup needed.** The script automatically reads Pi's own credentials from `~/.pi/agent/auth.json` — the same keys you configured via `/login` in Pi.

Only if Pi has no credentials configured, ask the user to set an environment variable:

```bash
export DEEPSEEK_API_KEY=sk-xxx   # or OPENAI_API_KEY, AI_API_KEY
```

## Usage

### Full Analysis (recommended)

Run ONE command in the user's Vue 3 project root:

```bash
cd <project-root> && node {baseDir}/scripts/vue-auth-api-analyzer.mjs --run-ai
```

This automatically:
1. Static AST analysis (Vue SFC → v-auth → @click → handler → request() → HTTP URL)
2. Groups unmatched buttons by module, prepares AI tasks
3. Calls LLM to analyze remaining buttons (cached modules skipped)
4. Merges static + AI results into final report

**Do NOT add --ndjson** — let progress stream naturally so the user can see it.

### Present Results

Read the report via bash (not the read tool, which adds line numbers):

```bash
node -e "const d=require('.auth-analyzer/auth-mapping-merged.json'); console.log(JSON.stringify(d.stats, null, 2)); d.pages.forEach(p => { console.log('\n## ' + p.page); p.buttons.forEach(b => { const apis = b.apis.map(a => a.method + ' ' + a.url).join(', ') || '(UI only)'; console.log('  ' + b.authId + ' → ' + apis + ' [' + b.source + '/' + b.confidence + ']'); }); })"
```

Present to the user:
1. Coverage statistics
2. Per-page button-permission-API mapping table (with HTTP method + URL)
3. Low-confidence / failed entries
4. Recommendations

## Output Files

All output in `.auth-analyzer/` under the project root:

| File | Purpose |
|------|---------|
| `auth-mapping-merged.json` | **Final merged report** |
| `static/<module>.json` | Per-module static analysis |
| `ai-tasks/<module>.json` | Per-module AI tasks (with prompts) |
| `ai-results/<module>.json` | Per-module AI results |
| `.ai-auth-cache.json` | Incremental cache |

## Configuration

Edit `CONFIG` in `{baseDir}/scripts/vue-auth-api-analyzer.mjs`:

| Setting | Default | Description |
|---------|---------|-------------|
| `viewsDir` | `src/views` | Vue pages directory |
| `authDirectiveName` | `auth` | Use `permission` for v-permission |
| `i18nFile` | `src/lang/package/zh-cn.ts` | Set `null` to skip i18n |
| `excludePatterns` | `["**/components/**", ...]` | Directories to exclude |
